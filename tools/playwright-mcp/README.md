# Playwright MCP Config Templates

These templates are local examples for wiring a Playwright MCP server into your MCP client.

## Files
- `mcp.playwright.extension.example.json` - extension-backed mode (`--extension`)
- `mcp.playwright.cdp.example.json` - CDP-backed mode (`--cdp-endpoint=chrome`)

## Usage
1. Copy the template content into your MCP client config.
2. Restart your MCP client.
3. Verify Playwright tools are available before running Gmail automation tasks.
