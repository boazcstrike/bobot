# Instagram Content Plan Tools

This folder contains reusable scripts for generating monthly Instagram content plans aligned with the Execution OS offer.

## Scripts
- `generate-monthly-plan.js`: generates a 30-day markdown plan with hooks, reel/carousel ideas, and CTA mapping.

## Usage
```bash
node tools/instagram-content-plan/generate-monthly-plan.js
```

Optional output path:
```bash
node tools/instagram-content-plan/generate-monthly-plan.js docs/plans/13-30-day-instagram-content-plan-next-month.md
```

Default output:
- `docs/plans/generated-30-day-content-plan.md`
