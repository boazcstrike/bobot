# 04 - Funnel and Sales System

## Funnel Architecture
Instagram content -> CTA (comment/DM/link) -> lead capture or checkout -> onboarding email/DM -> testimonial request

## Funnel Options
1. DM-first funnel (recommended for initial stage)
2. Link-click funnel (scale stage)

## DM-First Flow
1. User comments keyword
2. Auto or manual DM with short qualifier
3. Send value snippet + product link
4. Follow-up at 24h and 72h

## Conversion Assets
- Link-in-bio landing page
- Product sales page (problem, promise, proof, price, FAQ)
- Simple checkout
- Post-purchase delivery + onboarding message

## Weekly Sales Rhythm
- 2 direct sales posts/week
- 2 soft-sell educational posts/week
- Story selling window: 2-3 days/week

## Baseline Conversion Targets
- Reel view -> profile visit: 1.5%+
- Profile visit -> link click: 15%+
- Link click -> purchase: 2-5% early stage
- DM conversation -> purchase: 10-20% with strong fit

## Optimization Priorities
1. Improve hook rate (watch time)
2. Improve profile clarity and offer statement
3. Improve DM script response rate
4. Improve checkout conversion
