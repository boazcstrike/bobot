## 3) Simple Funnel (Reel -> Purchase)

## Funnel Overview
1. Reel gets attention
2. Viewer takes CTA action
3. DM conversation qualifies and builds trust
4. Product link sent with clear promise
5. Follow-up closes undecided leads

## Step-by-Step Flow

### Step 1 - Reel content
- Hook: pain or myth-bust
- Body: one tactical shift
- CTA: "Comment `OS` and I will send the setup checklist"

### Step 2 - Comment capture
- You manually or automatically DM everyone who commented `OS`
- Use the Step 1 message above

### Step 3 - Qualify quickly
- Ask one question: checklist first or full details
- Then ask biggest problem (planning/focus/follow-through)

### Step 4 - Offer bridge
Use this transition:
"Based on what you said, Execution OS solves exactly that with a weekly dashboard + daily workflow + review loop."

### Step 5 - Purchase moment
- Send checkout link
- Repeat the one-line promise:
"Install your execution system in 60 minutes."

### Step 6 - Follow-up and recovery
- 24h follow-up for silent leads
- 72h final follow-up
- Log result: bought / not now / wrong fit

## Minimal Weekly Metrics to Track
- Reel views
- Keyword comments
- DM conversations started
- Checkout link clicks
- Purchases

## Benchmarks to Aim For (early stage)
- Comment-to-DM start rate: 80%+
- DM-to-link rate: 50%+
- Link-to-purchase rate: 5-15%

## Keep It Repeatable Every Month
1. Keep one keyword for 2 weeks at a time.
2. Reuse the same DM framework with improved examples.
3. Rotate only hooks and proof stories; keep funnel structure fixed.
