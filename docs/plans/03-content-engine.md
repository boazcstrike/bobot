# 03 - Content Engine

## Primary Channels
- Reels (reach)
- Carousels (authority + saves)
- Stories (trust + conversion)

## Weekly Cadence (20h/week constraint)
- 4 Reels
- 2 Carousels
- Daily Stories (5-10 frames/day)
- 1 Live or long-form Q&A every 2 weeks

## Production Workflow
1. Monday: topic research + scripts
2. Tuesday: batch record reels (voice-first)
3. Wednesday: edit + publish + engage
4. Thursday: carousel design + CTA testing
5. Friday: analytics review + next-week optimization

## Content Pillar to Offer Mapping
- Focus pillar -> weekly planning module
- Mindset pillar -> reset prompts module
- Execution pillar -> daily workflow module

## CTA System
Use one CTA per post only:
- Comment keyword for guide
- DM keyword for product details
- Link in bio for direct checkout

## Hook Frameworks
- Mistake: "You are not lazy, your system is broken"
- Contrarian: "Motivation is optional; structure is not"
- Tactical: "3 steps to plan your week in 15 minutes"

## Story Sequence for Sales Days
1. Pain recognition
2. Personal insight or case
3. Quick win
4. Product bridge
5. Direct CTA
