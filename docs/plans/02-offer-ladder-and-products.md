# 02 - Offer Ladder and Products

## Offer Ladder
1. Free: checklist or mini guide (lead magnet)
2. Low-ticket core ($19-$49): template/guide bundle
3. Optional upsell ($79-$149): implementation pack or workshop

## First Product Recommendation
**Product name (working):** Execution OS for Busy Professionals

## Format
- Notion template + PDF playbook + weekly review worksheet

## Core Promise
Install a repeatable weekly execution system in under 60 minutes.

## Product Modules
1. Weekly planning dashboard
2. Daily focus workflow
3. Priority scoring framework
4. Mindset reset prompts for high-stress weeks
5. Review and improvement loop

## Pricing Strategy
- Launch: $19-$29 for first 30-50 buyers
- Standard: $39-$49 after social proof and testimonials

## Validation Goal
Sell to first 20 buyers before expanding product scope.

## Proof Strategy (No Prior Results)
- Recruit 5-10 pilot users at low/no cost in exchange for feedback and testimonials.
- Document before/after outcomes.
- Convert outcomes into carousels, reels, and product page proof.
