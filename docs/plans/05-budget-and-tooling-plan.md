# 05 - Budget and Tooling Plan

## Monthly Budget Cap
PHP 50,000 (~$1,000)

## Suggested Allocation
- Tools/software: $150-$250
- Content support (editing/design assistance): $200-$350
- Growth experiments (ads/collabs): $250-$350
- Contingency/testing reserve: $100-$150

## Recommended Stack
- Content creation: CapCut, Canva
- Product host: Gumroad or Lemon Squeezy
- Lead capture/email: ConvertKit or Beehiiv
- Landing pages: Carrd/Framer/Notion + custom domain
- Automation: Make/Zapier (only when manual process is proven)
- Analytics: native IG insights + simple weekly sheet

## Tooling Principles
1. Start cheap and stable.
2. Avoid automation before process clarity.
3. Keep integration minimal in first 60 days.

## Implementation Note
As a developer, custom tooling can be a leverage advantage later. Do not build custom infra before first 20-50 sales.
